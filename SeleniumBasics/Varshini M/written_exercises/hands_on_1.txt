Hands-on Exercise 1: Selenium Setup and First Browser Launch

Question:
Write a Python program using Selenium to launch a browser, open Google, maximize the window, and print the page title.

Answer:
Use Selenium WebDriver with ChromeDriver to open the browser, navigate to the target URL, and print the title.

Python code:
from selenium import webdriver
from selenium.webdriver.chrome.service import Service
from webdriver_manager.chrome import ChromeDriverManager


def main():
    driver = webdriver.Chrome(service=Service(ChromeDriverManager().install()))
    driver.maximize_window()
    driver.get("https://www.google.com")
    print("Page title:", driver.title)
    driver.quit()


if __name__ == "__main__":
    main()
