# Hands-on 2: Django Models, ORM, and Admin

This folder contains a Django project for the Course Management API domain with:

- Department, Course, Student, and Enrollment models
- Migrations applied to SQLite
- ORM examples for filtering, aggregation, select_related, and F() updates
- Django admin registration with custom CourseAdmin configuration

Run:

- python manage.py runserver 127.0.0.1:8001
- Visit http://127.0.0.1:8001/admin/
- Login with admin / Admin@123
